# Python File Management System

## About the Project

A simple file management system built using Python. It allows users to create, read, update, rename, and delete files through a menu-driven interface.

## Features

* Create new files
* Read file contents
* Rename existing files
* Overwrite file contents
* Append content to files
* Delete files with confirmation
* Handle invalid inputs and file-related errors
* Interactive menu with an exit option

## Technologies Used

* Python
* pathlib
* os
* File Handling
* Exception Handling
* Functions and Loops
